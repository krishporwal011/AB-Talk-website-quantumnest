## 🚀 Overview

**ABTalks 60-Day Challenge** is a mobile-first, interactive coding challenge platform built around one simple idea:

> **Consistency compounds.**

Instead of learning through endless tutorials, students are encouraged to build something every day for 60 days.

Each challenge day represents a small step toward becoming a stronger developer.

The platform combines:

- Daily coding challenges
- GitHub proof of work
- LinkedIn learning posts
- Streak tracking
- XP and achievements
- 60-day progress visualization
- Momentum analytics
- Interactive challenge checklists
- Submission workflows
- Gamified feedback
- Edge-case simulation
- Cinematic motion-driven UI

The current implementation is a **frontend MVP / functional prototype** using client-side state and browser `localStorage`.

# 🎯 The Problem

Many students learn software development through:

- Tutorials
- Courses
- Videos
- Coding problems
- Short-term projects

But learning does not automatically create consistency.

Students frequently experience:

- Tutorial hell
- Abandoned projects
- Inconsistent coding habits
- Lack of public proof of work
- Difficulty demonstrating practical skills
- Weak developer portfolios
- Little visibility beyond resumes

ABTalks approaches the problem differently.

Instead of asking:

> "How much did you study?"

ABTalks asks:

> **"What did you build today?"**
